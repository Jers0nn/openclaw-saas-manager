# OpenClaw SaaS Manager

Manage SaaS customers, subscriptions and usage directly from OpenClaw.

## Features

- List customers
- Search customers
- Get customer details
- Create customers
- List subscriptions
- Get customer usage

## Configuration

Configure:

{
  "apiUrl": "https://api.example.com/v1",
  "apiKey": "YOUR_API_KEY"
}

## Example

Ask OpenClaw:

"Find customer john@example.com"

"Show active subscriptions"

"Show usage for customer 123"

"Create a customer called Acme Corp with email admin@acme.com"
